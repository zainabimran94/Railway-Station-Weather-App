# Railway Station Weather App

A simple weather-based application that simulates train movement based on current weather conditions. Built using **vanilla JavaScript**, **HTML**, and **CSS**, with real-time data from a weather API.

### Demo Link
[Railway Station Weather App](https://railway-station-weather-app.vercel.app/)

## Overview

This app checks the current weather conditions and determines whether the train can move or not:
- **Clear Weather**: The train moves as scheduled.
- **Rainy, Snowy, or Foggy Weather**: The train remains stationary, and passengers are informed about the delay due to adverse conditions.

## Features

- Fetches real-time weather data using a weather API.
- Dynamic train movement based on favorable weather conditions.
- Provides weather updates to passengers when the train cannot operate.

## Tech Stack

- **JavaScript (Vanilla)**: Handles the logic for train movement and weather conditions.
- **HTML & CSS**: Frontend structure and styling.
- **Weather API**: Fetches real-time weather information.

## How It Works

1. The app retrieves the current weather data for the station location.
2. Based on the weather, the app simulates train movement:
   - If the weather is clear, the train moves.
   - If there is rain, snow, or fog, the train stops, and passengers are notified of the delay.
